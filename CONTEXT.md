# Contexto da Conversa - DevShowcase

## O que foi feito
- Projeto DevShowcase criado do zero: API REST com FastAPI para portfólio de desenvolvedor
- Estrutura: FastAPI + SQLAlchemy + SQLite + JWT + bcrypt
- 14 endpoints: auth (registro/login), CRUD de projects/skills/experiences, portfólio público
- Testes: 8/8 passando com pytest
- Dockerfile pronto
- README.md profissional com badges e documentação completa
